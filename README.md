# Decentralised Infrastructure Monitoring Simulator Platform

## 📌 Overview
This project simulates a decentralised infrastructure monitoring system designed to analyse real-time data from multiple nodes and support intelligent decision-making for system reliability and maintenance.

## 🚀 Features
- Simulated distributed nodes generating real-time infrastructure data
- Decentralised data collection and processing
- Anomaly detection for performance issues
- Data analytics and visualisation
- Scalable and fault-tolerant design

## 🛠️ Tech Stack
- Python
- Pandas, NumPy
- Jupyter Notebook
- Matplotlib / Plotly

## 🧠 Architecture
The system simulates multiple nodes sending data to a decentralised processing layer where it is analysed to detect anomalies and performance issues.
